# Core Features Website

A modern, responsive website showcasing the core features of an educational management system.

## Features Included

1. **Results Analysis** - Analyze results with ranks, GPA, division and position of students, subjects and teachers.
2. **Report Generation** - Generate examination results reports, print or export them to various formats.
3. **SMS Notifications** - Send a summary of students' results to their parents automatically and with zero setup.
4. **Topic Coverage Analysis** - Monitor what topics and sub topics are taught or not taught at district, school and specific subject level.
5. **NECTA Results Analysis** - Automatic analysis of your schools (at district, regional or national level) when NECTA exam results are released.
6. **Attendance Tracking** - Track students that attend school on a daily basis and easily notify parents of truancy. Made simpler with mobile app.
7. **Timetable Generation** - In one click, generate a collision free teaching timetable for your school. Customize it to fit your school's needs.
8. **Free T/L Materials** - Schemes of work, lesson plans, past papers, teacher's logbook, books and syllabuses, all in one place and free!

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/scottsric4t4/core-features-website.git
   ```

2. Open `index.html` in your web browser.
